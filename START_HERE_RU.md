# Как открыть и сдать проект

1. Распакуй **весь архив**, сохраняя структуру папок.
2. Для просмотра без установки программ открой `notebook.html` в браузере.
   В нём уже есть таблицы, графики, код и результаты.
3. Для работы в Jupyter открой `notebook.ipynb`. Если Jupyter ещё не установлен
   или хочешь запускать код заново, выполни установку из README в отдельное
   окружение и выбери в Jupyter ядро **Python (concrete-strength)**.

## Что находится в проекте

- `notebook.ipynb`: данные, графики, сравнение моделей и итоговые результаты.
- `notebook.html`: та же работа для просмотра в браузере без выполнения кода.
- `train.py`: повторное обучение выбранной модели с сохранением в `model.pkl`.
- `predict.py` и `serve.py`: приложение, которое принимает состав смеси и выдаёт
  предполагаемую прочность.
- `sample_request.json`: пример состава смеси для запроса.
- `Dockerfile`: сборка контейнера с приложением.
- `README.md`: описание для проверяющих и команды запуска.
- `data/`: исходные данные, CSV, источник и контрольные суммы.
- `results/`: измеренные результаты, графики и отчёты проверки.
- `results/container_request_screenshot.jpg`: настоящий скриншот живого запроса
  к контейнеру на сервере и полученного ответа HTTP 200.
- `verification/demo_client.py`: небольшой клиент для повторения этой проверки
  в браузере. Команды приведены в README.

Все количества компонентов указаны в кг на кубический метр, возраст в днях,
прочность в МПа. Это учебная модель, а не замена лабораторному испытанию.

## Что нужно для сдачи

Репозиторий проекта: https://github.com/kirillkaryagin/concrete-strength-prediction.
Он содержит ноутбук, данные, скрипты, зависимости, модель и Dockerfile.

В форме курса укажи ссылку на репозиторий и Commit ID окончательной версии.
Commit ID обозначает конкретную сохранённую версию файлов. Время работы укажи
фактическое. Поля Learning in public и FAQ необязательные. Проверь имя для
сертификата и нажми Save submission. После сдачи нужно оценить три чужих проекта.

Commit ID можно скопировать со страницы последнего коммита GitHub или получить
в папке локального клона командой `git rev-parse HEAD`.

Форма курса заполняется отдельно. API после проверки остановлен.
Для самостоятельного запуска используй команды в README.
Адрес `127.0.0.1` означает этот же компьютер.

Проект повторно проверен из чистого клона GitHub в новом Python-окружении:
ноутбук, отдельное обучение и API работают, предсказания совпадают с первой
версией. Контейнер проверен через опубликованный порт хоста.
